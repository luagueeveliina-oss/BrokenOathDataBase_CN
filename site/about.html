数据从哪里来

本站有两类数据，来源和更新节奏不同：

  • 天梯、构筑、环境统计：来自 Broken Oath public API。这是一个面向工具作者的公开只读 JSON API，不需要密钥、没有登录、CORS 开放。天梯每 15 分钟刷新，构筑与统计每小时刷新。
  • 物品、技能、天赋、图鉴：由本站从本机安装的 Playtest 游戏数据文件生成（当前本地数据 0.56.8 / 被动树 v18）。游戏更新后需要重新运行构建脚本。
  • 模拟构筑器：DPS / 面板 / 命中 / 异常 / 魔力 参考自 Broken Oath Builder 实现。
本站不会抓取游戏服务器、登录接口或游戏内天梯；只使用公开 API 的文件。天梯与构筑的署名：Data: Broken Oath public API。

同步与缓存

API 文档明确要求「在自己这一侧缓存，把读者从你的副本上服务，不要每位访客都回源请求」。本站因此不在页面加载时自动访问 API：

  • tools/sync_api.py 在构建/部署阶段拉取快照，写入 site/assets/api/，并生成一份供 file:// 直接打开用的同步种子。
  • 页面优先读取本站快照；只有在快照缺失、或读者主动点击「检查更新」时，才会直接读取公开 API。
  • 快照带有 generated_at、ladder_updated_at、builds_updated_at 与本站同步时间，页面会如实显示，不伪装成实时。
  • GitHub Actions 在发布前运行同步脚本，因此线上副本不会落后超过一个公开 API 刷新周期。

隐私与英雄身份

  • API 文件里没有任何玩家姓名、Steam id、账号 id、邮箱或 IP；英雄 id 是不可逆的加盐哈希。
  • 本站只展示这个匿名 id 的前几位用于区分同一份构筑，不会、也无法把英雄对应到任何真实玩家。
  • 作弊标记、封禁、退出遥测、主动要求隐藏的英雄不会出现在公开文件里。
  • 本站没有统计脚本、没有广告、没有第三方追踪；主题与语言偏好只存在浏览器本地。

Alpha 与字段变化

公开 API 仍是 alpha：字段可能增加或改变，数字、技能与流派会随补丁移动。本站读取时会检查 schema 与 generated_at，忽略不认识的字段；如果某份构筑已经离开前 50、被删除或玩家取消公开，构筑详情页会显示「没有找到」，而不是缓存一份过期数据。

中文与版本

本站优先使用游戏内官方中文；只有当官方中文不存在时（例如 0.56.8 新增、而本地游戏仍是 0.56.5 的内容），才保留英文原名。物品与技能页会标注本地数据版本，天梯与构筑页则显示公开 API 补丁号，两者可能不同。

技术

  • 纯静态站点：HTML + CSS + 原生 JavaScript，无框架、无后端。
  • 深链接：物品、技能、图鉴、天梯联赛、构筑详情都可以直接分享。
  • 明暗主题；构筑模拟器在浏览器内完成全部计算。
  • 图表使用 CSS 与内联 SVG 绘制，不加载图表库。
